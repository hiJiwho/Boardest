교사용 기능 가이드: 쪽지, 수행평가, 설정

선생님 앱(Boardest Teacher)의 실시간 교실 쪽지 전송, 다중 반 수행평가 일괄 공지, 동료 교사 시간표 병합 기반 평가 일정 AI 최적 추천 활용법을 안내합니다.

1. 실시간 교실 쪽지 & 긴급 공지 발송

교무실에 앉아서 각 반 전자칠판 대화면으로 실시간 쪽지를 전송할 수 있습니다.

  • 수신 대상 선택: 내가 담임을 맡은 반, 특정 이동수업 교실, 또는 전체 교실을 선택할 수 있습니다.
  • 실시간 팝업 안내: 전송 즉시 해당 교실 전자칠판 상단에 슬라이드 배너가 나타나며, 학생들이 수업 전 중요한 준비물이나 공지사항을 놓치지 않도록 돕습니다.

2. 수행평가 다중 반 일괄 공지 등록 (NEW v5.3.5)

같은 과목을 여러 반(예: 1반부터 8반)에 걸쳐 가르치는 교과 선생님들을 위해 반별 일괄 등록 인터페이스를 제공합니다.

🎯 일괄 등록 절차:
1. 좌측 메뉴에서 [📝 수행평가] 탭을 클릭합니다.
2. 과목명(예: 수학), 평가명(예: 이차방정식 서술형 평가), 준비물 및 평가 범위를 입력합니다.
3. 하단 학급 목록에서 1반(월 2교시), 2반(화 1교시), 3반(화 3교시)... 등 각 반별 실시 일시를 한 화면에서 표 형태로 빠르게 지정합니다.
4. [한 번에 공지 배포]를 클릭하면 모든 해당 학급 전자칠판의 수행평가 칸에 실시간으로 등록됩니다.

3. 동료 교사 시간표 병합 & 주간 달력 히트맵 (AI 최적 일정 추천)

수행평가를 잡을 때 가장 큰 고민은 다른 과목(국어, 영어 등)과 시험 일정이 겹쳐 학생들이 힘들어하는 것입니다.

  • 동료 교사 시간표 병합: 동료 교사(예: 수학과 김선생님, 영어과 박선생님)를 기입하면, 두 선생님의 수업 시간표와 이미 등록된 타 교과 수행평가 데이터가 하나로 합쳐집니다.
  • 주간 캘린더 히트맵: 특정 요일과 교시에 평가가 얼마나 몰려있는지 색상 농도(녹색: 여유 → 빨간색: 과밀)로 시각화해 드립니다.
  • AI 황금 일정 추천: "11월 2주차 화요일 3교시에 3반을 진행하면, 다른 주요 과목과 겹치지 않고 3일 안에 모든 반 평가가 마무리됩니다!" 와 같은 최적 일정을 자동으로 제안받을 수 있습니다.

4. 컴시간 / 나이스 시간표 연동 및 설정 관리

선생님의 주간 수업 시간표를 자동으로 동기화하고 개인 맞춤형 환경을 설정합니다.

  • 시간표 새로고침: 학교 시간표가 수시로 변경(교체 수업, 보강 등)되더라도 [시간표 새로고침] 버튼을 누르면 컴시간 서버의 최신 시간표로 1초 만에 갱신됩니다.
  • A4 인쇄 & 엑셀 내보내기: 등록된 반별 수행평가 계획표는 교무일지 보관용 A4 인쇄 서식이나 Excel(.xlsx/CSV) 파일로 원클릭 저장할 수 있습니다.
