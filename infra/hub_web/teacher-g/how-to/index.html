✨ 초보 선생님을 위한 3분 마스터 매뉴얼

선생님, 이것만 알면 5분 만에 수업 준비 끝!

복잡한 설정이나 비밀번호 암기 없이, 스마트폰 지문 인증(Passkey)과 1초 QR 로그인으로 교무실과 교실 전자칠판을 자유자재로 연결해보세요.

🚀 3단계 초간단 빠른 시작 가이드

처음 사용하는 선생님도 그대로 따라 하시면 3분 안에 완벽히 연동됩니다.

1
내 폰에 패스키 등록

휴대폰 브라우저로 boardest-teacher-oauth.web.app에 접속해 구글 로그인 후 [이 기기를 패스키로 등록]을 누릅니다. 지문/Face ID 한 번 찍으면 등록 완료!

최초 1회만 등록
2
교실 칠판 QR 1초 로그인

교실 전자칠판의 Boardest Class Cloud 화면에 뜬 QR 코드를 스마트폰 기본 카메라로 찰칵 스캔하세요. 학생들 보는 앞에서 비번 칠 필요 없이 즉시 안전하게 로그인됩니다!

비밀번호 노출 원천 방지
3
수업 후 1초 원격 로그아웃

수업이 끝나면 내 휴대폰 화면에서 [전자칠판 로그아웃] 버튼을 누르거나, 칠판의 [로그아웃]을 누르면 내 개인 파일이 교실에서 즉시 닫힙니다.

수업 후 보안 완벽 보장

💡 가장 많이 쓰는 핵심 기능 4가지

💬 1. 교무실에서 교실 전자칠판으로 실시간 쪽지 & 공지 보내기

학생들이 수업 시작 전 깜빡하기 쉬운 준비물이나 긴급 전달사항을 교무실 자리에서 바로 보낼 수 있습니다.

  • 어디서 보내나요? 교무실 PC의 Boardest Teacher 앱 또는 웹 포털의 [쪽지 보내기] 탭에서 작성합니다.
  • 누구에게 가나요? 우리 담임반, 내가 수업 들어가는 특정 교실, 또는 전 학년 전체 교실을 선택해 전송할 수 있습니다.
  • 칠판에는 어떻게 뜨나요? 해당 반 전자칠판 상단에 슬라이드 팝업 배너 형태로 나타나며, 학생들이 수업 전 또렷하게 확인하게 됩니다.
💡 선생님 꿀팁: 1교시 수업 전 "오늘 3반은 3교시에 과학실로 이동합니다! 교과서 챙겨오세요."와 같은 알림을 5초 만에 보낼 수 있습니다.

📝 2. 여러 반 수행평가 일괄 공지 등록 (1반~8반 한 번에!)

동일한 과목을 여러 반에 걸쳐 수업하시는 교과 선생님들을 위해, 각 반별 평가 일정을 표 하나에서 일괄 등록할 수 있습니다.

  1. 좌측 메뉴에서 [수행평가] 탭을 클릭합니다.
  2. 과목명(예: 수학)과 평가 제목(예: 이차방정식 서술형 평가), 평가 범위 및 준비물을 적습니다.
  3. 아래 학급 목록에서 1반(월 2교시), 2반(화 1교시), 3반(화 3교시)... 표에 날짜와 교시를 콕콕 찍어 선택합니다.
  4. [한 번에 공지 배포]를 누르면 각 교실 전자칠판의 수행평가 칸에 실시간으로 등록됩니다!
💡 자동 알람 기능: 시험 전날에는 칠판에 [내일 수행!], 당일에는 [오늘 수행!] 뱃지가 자동으로 깜빡여 학생들이 일정을 놓치지 않습니다.

🤝 3. 동료 교사 일정 합치기 & 시험 겹침 방지 (AI 최적 일정 추천)

수행평가를 잡을 때 국어, 영어, 수학 일정이 겹쳐 학생들이 힘들어하지 않도록 다른 선생님의 일정과 겹치지 않는 황금 요일을 찾아드립니다.

  • 동료 선생님 검색: 같은 학년 다른 과목 선생님을 추가하면 두 분의 수업 시간표와 이미 잡힌 평가 일정이 하나로 합쳐집니다.
  • 주간 히트맵 색상 안내: 녹색(여유)부터 붉은색(과밀)까지 어느 요일에 시험이 몰려 있는지 한눈에 보입니다.
  • AI 최적 추천: "다음 주 화요일 3교시에 진행하면 다른 중요 시험과 겹치지 않습니다!" 안내에 따라 클릭 한 번으로 확정할 수 있습니다.

⏰ 4. 나이스 / 컴시간 시간표 1초 동기화 & A4 인쇄

갑작스러운 교체 수업이나 보강 일정도 걱정 마세요. [시간표 새로고침] 버튼 한 번으로 학교 서버의 최신 시간표를 즉시 반영합니다.

  • 교무일지 보관용으로 수행평가 계획표를 깔끔한 A4 양식으로 인쇄하거나 Excel(.xlsx)로 내보낼 수 있습니다.

❓ 초보 선생님이 자주 묻는 질문 (FAQ)

❓ 학생들이 보는데 비번을 치기 불안해요.
비밀번호를 교실 칠판에 타이핑할 필요가 전혀 없습니다! 스마트폰 카메라로 QR 코드를 비추고 휴대폰 지문만 찍으면 칠판에 내 수업자료가 즉시 열립니다.
❓ 수업 끝나고 칠판 로그아웃을 깜빡했어요!
교무실로 돌아와서 스마트폰을 켜고 [전자칠판 로그아웃]을 누르면 교실 화면이 원격으로 즉시 잠깁니다. 걱정하지 마세요!
❓ 학생들도 제 개인 클라우드 파일에 접근하나요?
전자칠판용 Boardest Class Cloud는 열람 전용 모드로 작동하여 학생들이 임의로 파일을 수정, 다운로드, 삭제할 수 없습니다.
❓ 스마트 교과서(TBP) 판서도 가능한가요?
네! Boardest Class Cloud 전용 앱에서 TBP 교과서 및 PDF 학습지 위에 직접 필압 지원 펜으로 판서하고 필기 내용을 저장할 수 있습니다.
