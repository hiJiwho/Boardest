Teacher Manual / Part 1

교사 설치 & 세팅 완벽 가이드

교사용 앱(Boardest Teacher)의 회원가입부터 기기별(Windows, Android, Web) 설치 방법 및 차이점을 상세히 안내합니다.

1. 계정 생성 및 로그인 방법

Boardest 교사용 앱은 선생님의 수업 자료(Google Drive) 및 학교 시간표(나이스/컴시간)와 안전하게 동기화됩니다. 별도의 복잡한 회원가입 양식 없이 선생님의 구글 학교 계정 또는 개인 계정으로 1초 만에 시작할 수 있습니다.

🔑 로그인 절차:
1. 앱을 실행하거나 교사용 웹에 접속합니다.
2. [Google 계정으로 시작하기] 버튼을 누르고 학교/개인 계정을 선택합니다.
3. 첫 로그인 시 근무하시는 학교(예: '보데스트중학교')를 검색하여 선택하고, 담당 교과목 및 학년/반을 설정하면 계정 등록이 완료됩니다.

2. 플랫폼별 설치 및 실행 링크

선생님의 근무 환경에 맞춰 3가지 방식으로 자유롭게 이용하실 수 있습니다.

에디션 권장 기기 설치/접속 링크 주요 특징
Pro for Windows 교무실 PC, 노트북 온라인 통합 설치기 (installer.exe) 전체 기능 지원 (수행평가 다중 추천, 주간 히트맵, TBP/디지털교과서 편집, 백그라운드 자동 업데이트)
Pro for Android 태블릿, 패드, 스마트폰 boardest-teacher.apk 교실 이동에 최적화된 패키지 (시간표 확인, 교실 쪽지 전송, 클라우드 1회용 OTP 발급)
Web (무설치) 공용 PC, 맥북, 크롬북 boardest-teacher.web.app 설치 권한이 없는 환경에서도 브라우저만으로 시간표와 수업 관리 기능 즉시 사용 가능

3. Windows Pro 버전 설치 상세 가이드 (.msi)

  1. 다운로드 센터에서 boardest-teacher.msi 파일을 내려받아 더블 클릭합니다.
  2. 설치 마법사 창이 나타나면 [다음]을 눌러 표준 경로(C:\Program Files\Boardest Teacher)에 설치합니다.
  3. 바탕화면에 생성된 Boardest Teacher 아이콘을 실행하면 즉시 실행됩니다.
⚠️ Windows SmartScreen 안내 창이 뜰 경우:
학교 보안 정책에 따라 파란색 보호 화면이 나타나면 추가 정보를 클릭한 뒤 실행 버튼을 눌러주시면 정상 진행됩니다.

4. Android Lite 버전 설치 안내 (.apk)

교실 이동이 잦은 선생님을 위해 군더더기를 뺀 Lite 에디션을 제공합니다.

  • 태블릿의 웹 브라우저에서 boardest-teacher-lite.apk 파일을 다운로드합니다.
  • 다운로드 완료 알림을 눌러 실행하고, '출처를 알 수 없는 앱 설치 허용'을 활성화한 후 설치를 마칩니다.
  • 실행 후 학교와 선생님 성함을 입력하면 즉시 모바일 시간표 및 교실 원터치 연동 OTP가 활성화됩니다.
