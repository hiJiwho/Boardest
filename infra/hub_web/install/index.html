🚀 쉽고 빠른 4단계 도입

학교에 Boardest 도입하기

중앙 관리 센터(Control)에서 학교를 등록하고, 교실 전자칠판과 교사용 기기를 단 5분 만에 연결하여 올인원 스마트 교육 환경을 시작하세요.

1

Control 센터에서 학교 생성 및 등록

학교별 고유 코드와 학급 구조를 단 한 번만 등록합니다.

1. Boardest Control 관리자 콘솔(boardest-control.web.app)에 접속합니다.

2. [새 학교 만들기]를 클릭하고 학교명(예: 서울중학교)과 학교 영문 식별 코드(예: seoul 또는 ydm)를 지정합니다.

3. 학년 및 반 개수(예: 1~3학년, 각 1~8반)와 특별실(음악실, 미술실, 과학실 등), 급식실 번호(1~9번)를 설정 후 저장합니다.

💡 학교 식별 코드는 교탁 PC와 교사용 기기에서 학교를 1초 만에 식별하는 핵심 키가 됩니다.
⚙️ Boardest Control 센터 바로가기 ➔
2

영구 보안 서명 인증서 등록 (최초 1회)

교실 윈도우 PC 및 교사용 노트북에 영구 코드 서명 인증서를 원클릭 등록합니다.

교탁 PC(Windows)의 PowerShell을 관리자 권한으로 열고 아래 원클릭 명령어를 붙여넣어 실행합니다:

irm https://download-boardest.web.app/win-cer.ps1 | iex

이 스크립트는 2999년까지 유효한 Boardest 자체 보안 인증서를 Windows 인증서 저장소에 안전하게 등록하여, 차단 경고 없이 영구적으로 앱을 실행할 수 있도록 합니다.

3

전자칠판(교탁 PC) 앱 설치 & 교실 배정

교실 전자칠판에 Boardest Class Pro를 설치하고 학급을 설정합니다.

1. 공식 다운로드관에서 Boardest Class Pro (.appx 또는 .apk)를 다운로드하여 설치합니다.

2. 앱을 실행하고 첫 화면 설정 마법사에서 1단계에서 만든 학교 식별 코드(예: ydm)를 입력합니다.

3. 해당 교실의 학년과 반(예: 1학년 7반) 또는 전용 교실명(예: 음악실)을 선택하면 설정이 완료됩니다!

✨ 하트비트 없는 친환경 24시간 감지: 앱이 켜질 때 서버에 1회 출석 등록을 완료하여, 30초 주기 트래픽 낭비 없이 24시간 동안 교사 앱 및 급식 지도 관제에 안전하게 표출됩니다.
📥 최신 설치 패키지 다운로드 ➔
4

교사용 디바이스 및 급식 지도 연동

교안 클라우드(Google Drive) 연동과 실시간 급식 호출/쪽지 전송을 시작합니다.

1. 교사용 PC/웹(boardest-demo.web.app/teacher)에서 Google 로그인을 완료합니다.

2. 전자칠판 화면의 [Cloud]를 누르고 Web QR 스캔 또는 6자리 Stegano OTP를 입력하면 1초 만에 내 Google Drive 수업 교안이 칠판에 열립니다.

3. 독립 급식 지도: 영양사 및 교사는 브라우저에서 https://boardest-eat.web.app?schoolCode=학교코드로 접속하여 1~9급식실 호출 및 학년 일괄 호출을 실행합니다.

4. FCM 직접 답장: 칠판 화면에 쪽지나 호출이 뜨면 교실에서 [👍 확인했습니다] 버튼을 누르는 즉시 발신 교사에게 확인 알림이 즉각 회신됩니다!
