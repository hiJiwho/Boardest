🎒 학생용 (Boardest Student — 로그인 없음)

Boardest Student (b student)

별도의 회원가입이나 로그인 없이 학교·학년·반만 선택하면 우리 반 시간표, 오늘/내일 급식(알레르기 필터), 실시간 수행평가 일정 조회 및 등록까지 즉시 이용할 수 있습니다.

⚡ 로그인 불필요 · PWA 지원
🌐 학생용 웹 포털 (boardest-student.web.app)
스마트폰, 태블릿, PC 브라우저 어디서나 홈 화면 추가(PWA) 지원
학생 포털 열기 🎒

🔐 Windows 자체 서명 인증서 원클릭 등록 스크립트

학교 PC나 Windows 전자칠판에서 AppX 패키지 설치 시 신뢰할 수 있는 루트 인증서 오류가 발생할 경우, 아래 PowerShell 명령어를 실행하시면 보데스트 공식 인증서가 시스템에 자동으로 등록됩니다.
