Cloud Security / Passkey Guide

클라우드 패스키(Passkey) 등록 및 사용 가이드

전자칠판 대화면에서 비밀번호 노출 없이 스마트폰 생체인증(지문/Face ID)과 QR 코드로 1초 만에 안전하게 로그인하는 패스키 인증 매뉴얼입니다.

1. 패스키(Passkey)란 무엇인가요?

교실 전자칠판은 학생들이 지켜보는 공개된 장소입니다. 칠판 화면에 구글 계정 비밀번호를 키보드로 입력하면 비밀번호가 노출되거나 저장될 위험이 있습니다.

🛡️ 패스키 보안의 핵심:
비밀번호를 입력하는 대신, 선생님 스마트폰의 지문, Face ID, 또는 화면 잠금 핀을 활용하여 강력한 공개키 암호화(FIDO2 / WebAuthn) 기반으로 인증합니다. 비밀번호 자체가 교실 전자칠판에 전달되지 않으므로 100% 안전합니다.

2. 선생님 패스키 등록 방법 (최초 1회)

  1. 선생님 연구실 PC 또는 스마트폰에서 Boardest Teacher 앱을 켭니다.
  2. 설정 메뉴의 [클라우드 보안 및 패스키 등록]으로 이동합니다.
  3. [새 패스키 등록]을 누르면 기기의 생체인증(지문 또는 얼굴 인식) 팝업이 뜹니다.
  4. 생체 인증을 완료하면 안전한 패스키 등록이 완료되며, 이제 교실 전자칠판 어디서나 이 패스키로 바로 승인할 수 있습니다.

3. 교실 전자칠판에서 QR 스캔 1초 로그인

수업을 위해 교실에 들어간 후 전자칠판을 켤 때 사용하는 방법입니다:

  1. 교실 전자칠판에서 Boardest Class 또는 BCLD (Class Cloud)를 엽니다.
  2. 화면에 표시되는 선생님 인증용 QR 코드를 확인합니다.
  3. 선생님의 스마트폰 기본 카메라로 전자칠판 QR 코드를 스캔합니다.
  4. 스마트폰 화면에 "2학년 3반 전자칠판에서 수업 자료 폴더 접근을 요청합니다" 메시지가 뜨면 [승인]을 터치하고 지문(패스키)을 댑니다.
  5. 전자칠판 화면이 즉시 선생님의 수업 폴더(bst-save, bst-tbp)로 열립니다.

4. 수업 종료 후 자동 보안 로그아웃

수업이 끝나면 전자칠판 상단의 [수업 종료 / 로그아웃] 버튼을 누르면 즉시 모든 토큰이 파기됩니다. 혹시 로그아웃을 잊고 교실을 나가시더라도, 쉬는 시간 타이머 종료 시 자동으로 세션이 닫혀 학생들이 자료를 열람할 수 없도록 이중 보호됩니다.
