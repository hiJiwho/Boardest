Boardest Pen & TBP Engine / Guide

클라우드 판서 기능, 저장 방식 & TBP 완벽 가이드

수업 판서 도구 활용법부터 Google Drive 클라우드 자동 저장 방식, 스마트 디지털 교과서(TBP / HTMLP)의 환경별 실행 안내를 다룹니다.

⚠️ 중요 안내: 디지털 교과서(TBP)는 일반 웹 브라우저에서 실행되지 않습니다!

출판사 스마트 디지털 교과서(.tbp, .htmlp)는 대용량 미디어 리소스 및 네이티브 로컬 렌더링 엔진, 파일 권한 규격으로 인해 일반 웹 브라우저(크롬, 사파리, 엣지 등 웹 환경)에서는 구동이 지원되지 않습니다.
TBP 디지털 교과서를 열고 수업을 진행하시려면 반드시 Windows 전용 앱(boardest.appx / boardest-teacher.msi) 또는 Android 전용 앱(boardest.apk / boardest-cloud.apk)을 설치하여 실행하셔야 합니다!

1. 클라우드 수업 판서 지원 기능 (Boardest Pen)

수업 중 전자칠판 위에 자유롭게 필기하고 설명할 수 있는 전문 수업 펜 도구를 기본 제공합니다:

  • 필압 반응형 펜: 스타일러스 펜의 압력과 속도에 반응하여 굵기가 자연스럽게 변화하는 부드러운 필기감
  • 형광펜 하이라이트: 디지털 교과서 본문이나 PDF 문제 지문의 글자를 가리지 않는 반투명 형광펜
  • 수학/과학 도형 도구: 반듯한 직선, 직사각형, 정원, 좌표 평면 화살표를 마우스/펜 드래그로 손쉽게 생성
  • 올빼미 레이저 포인터: 학생들의 시선을 집중시킬 수 있는 반짝이는 잔상 효과 포인터
  • 부분 지우개 & 올클리어: 손바닥이나 제스처를 인식하여 원하는 획만 골라 지우거나 칠판 전체를 즉시 정리

2. 판서 파일의 클라우드 자동 저장 방식

수업 중 필기한 소중한 판서 자료는 컴퓨터가 꺼지더라도 날아가지 않습니다.

📁 Google Drive 자동 동기화 구조:
• 선생님께서 판서 화면에서 [저장]을 누르면, 선생님의 구글 드라이브 내 bst-save/판서 또는 bst-pen 폴더에 날짜 및 교시별(예: 2026-10-29_2학년3반_수학판서.bstpen)로 자동 백업됩니다.
• 다음 날 다른 교실이나 연구실 PC에서 앱을 열었을 때, 이전 시간에 필기했던 판서 노트를 그대로 다시 불러와 연속해서 수업을 진행할 수 있습니다.

3. 스마트 디지털 교과서 (TBP / HTMLP) 활용법 (네이티브 앱 전용)

Windows 또는 Android 앱 환경에서 TBP 디지털 교과서를 수업에 연동하는 방법입니다:

  1. 출판사에서 제공받은 .tbp 파일 또는 .htmlp 교과서 파일을 교사용 앱(Boardest Teacher)을 통해 클라우드에 등록합니다.
  2. 교실 전자칠판 앱(Boardest Class 또는 BCLD)에서 해당 교과서를 탭하면 내장 TBP 통합 뷰어가 1초 만에 실행됩니다.
  3. 좌측 상단 목차 버튼을 눌러 원하는 단원과 페이지로 즉시 이동할 수 있습니다.
  4. 교과서 위에 바로 펜 도구를 띄워 문제 풀이를 판서하고, 필요 시 화면을 2분할하여 한쪽엔 교과서를, 다른 한쪽엔 빈 판서 연습장을 열고 수업할 수 있습니다.
