01
선생님 필수 기능

📱 스마트폰 QR 1초 로그인 (학교 계정/비밀번호 걱정 끝!)

교실 전자칠판에 긴 구글 아이디나 비밀번호를 공개적으로 입력할 필요가 없습니다. 학교 방화벽에서도 터치 한 번으로 안전하게 열립니다.
  • 1. 전자칠판에서 QR 띄우기: 교실 칠판 상단/우측의 Cloud 아이콘을 누르면 대형 로그인 QR 코드가 나타납니다.
  • 2. 선생님 폰으로 찰칵: 스마트폰 기본 카메라로 QR 코드를 비추면 즉시 선생님의 수업 교안, 시간표, 판서가 칠판에 로드됩니다!
  • 3. 보안 자동 종료: 수업이 끝나거나 자리를 비우면 일정 시간 후 자동으로 세션이 안전하게 종료됩니다.
✨ 초단축 모바일 주소: 스마트폰 브라우저에 bcld.web.app (단 4글자!)을 즐겨찾기해 두시면 언제 어디서든 즉시 교실 전자칠판과 연결됩니다.
02
자동화 & 낙서 분리

🧠 과목별 판서 자동 기억 & 쉬는시간 낙서 방지 시스템

"지난 시간 국어 판서 어디 갔지?" 더 이상 판서 파일을 날짜별로 일일이 찾거나 학생들의 쉬는시간 낙서 때문에 스트레스받지 마세요!
  • 국어시간 판서 ➔ 다음 국어시간에 자동 복원: 국어 수업에 들어가서 화이트보드를 켜면, 지난주/어제 국어 시간에 판서했던 내용이 그대로 이어서 열립니다!
  • 쉬는시간 낙서 완벽 분리: 종이 울리고 쉬는시간이나 점심시간에 화이트보드를 켜면 과목 판서가 아닌 '쉬는시간' 전용 보드가 열려, 학생들이 아무리 낙서해도 선생님의 소중한 수업 판서는 절대 덮어쓰여지지 않습니다.
  • 구글 드라이브 실시간 자동 백업: Cloud가 연결되어 있으면 판서 내용이 선생님 구글 드라이브(bst-pen 폴더)에 .pen.bst 형식으로 즉시 자동 저장됩니다.
03
TBP & 슬라이드 업그레이드

🎯 캔바(Canva) & 웹 교안 완벽 수업 (.web.bst)

캔바, 미리캔버스, 구글 슬라이드, 에듀넷 디지털교과서를 판서와 함께 한 화면에서 자유자재로 수업하세요.
  • 무선 프리젠터(클리커) 버그 완전 해결: 캔바에서 무선 클리커의 PgUp/PgDn을 누르면 첫/마지막 장으로 순간이동하던 문제를 해결하여, 이제 일반 PPT처럼 한 장씩 부드럽게 넘어갑니다!
  • 슬라이드별 판서 자동 기억 (256-bit dHash): 슬라이드를 다음 장으로 넘기면 이전 장 판서는 사라지고, 해당 페이지에 썼던 판서만 쏙 나타납니다!
  • ✨ v5.1.1 신규 펜 툴바 기능:
    • 형광펜 (반투명 하이라이터): 교과서 본문이나 슬라이드 중요 문장을 은은하게 강조할 수 있습니다.
    • 실행 취소 (Undo / Ctrl+Z): 잘못 그은 획을 버튼 하나로 즉시 되돌릴 수 있습니다.
    • 판서 즉시 저장 (Ctrl+S): 툴바의 저장 아이콘이나 Ctrl+S를 누르면 현재 슬라이드 판서가 영구 저장됩니다.
✨ 새 통합 규격 안내: v5.1부터 HTMLp와 TBP가 통일되어 모든 웹 교안은 .web.bst 규격으로 손쉽게 관리됩니다.
04
판서 보관함

📦 판서 보관함 & 4가지 포맷 추출 (언제 뭘 써야 할까요?)

작성한 판서를 판서 보관함에서 원하는 형식으로 언제든지 내려받거나 학생들에게 공유할 수 있습니다.
  • 1. .pen.save.bst (원본 보관용): 보데스트 전용 완전판 포맷! 파일 관리에서 드라이브에 업로드하기만 하면 판서 보관함에 자동으로 등록됩니다.
  • 2. .pdf (학생 배포 / 인쇄용): 수업 후 학생들에게 복습 유인물로 나누어 주거나 인쇄할 때 사용합니다 (더 이상 수정 불가).
  • 3. .svg (고화질 벡터 그림): 아무리 크게 확대해도 절대 깨지지 않는 무손실 벡터 일러스트로 각 페이지를 저장합니다.
  • 4. .iwb (전자칠판 공용 규격): 타사 전자칠판 기기나 타 소프트웨어로 판서를 가져갈 때 사용합니다. (전자칠판 표준 규격상 일부 특수 펜 스타일 유실 주의)
05
원클릭 설치

⚡ 2999년 영구 인증서 1줄 초간단 설치 (Windows / 전자칠판)

교실 전자칠판이나 학교 PC에 설치할 때 관리자 권한이나 인증서 오류로 고생하지 마세요. 파워쉘 1줄이면 2999년까지 만료되지 않는 영구 인증서가 자동 설치됩니다.
powershell -ExecutionPolicy Bypass -Command "irm https://boardest.web.app/install/cert.ps1 | iex"
  • USB 설치: USB에 복사된 boardest.appx (Windows 전자칠판용) 및 boardest.apk (안드로이드 전자칠판용)를 더블클릭하면 끝!
  • 무소음 & 부팅 지연 없음: 윈도우 시작 시 무겁게 백그라운드를 잡아먹지 않는 초경량 고속 구조입니다.

선생님들이 가장 자주 묻는 질문 (FAQ 5선)

속 시원한 해결책
❓ Q1. 구형 안드로이드 전자칠판에서 APK 설치가 안 돼요!
이전에 설치되어 있던 구버전 앱과 빌드 서명이 충돌하는 경우가 90% 이상입니다.
전자칠판의 [설정] ➔ [애플리케이션(앱 관리)]으로 이동하여 기존에 깔려 있는 `boardest` 앱을 완전히 [삭제(제거)]하신 후, USB의 새 `boardest.apk`를 설치하시면 즉시 정상 설치됩니다!
❓ Q2. 쉬는 시간인데 메인 화면에 왜 다음 교시 과목이 뜨나요?
선생님과 학생들이 쉬는 시간 동안 다음 수업(예: 3교시 수학)의 교과서와 자료를 미리 준비할 수 있도록 배려한 스마트 레이아웃입니다.
수업 중에는 '수업 진행 중' 뱃지가 뜨고, 쉬는 시간 및 점심 시간에는 '다음 수업 준비'로 똑똑하게 전환됩니다.
❓ Q3. 캔바 슬라이드를 넘길 때 판서는 어떻게 되나요?
보데스트의 dHash 화면 인식 기술이 작동하여, 슬라이드를 넘기면 현재 슬라이드의 판서는 안전하게 자동 저장되고 다음 슬라이드에 적어두었던 판서가 마법처럼 다시 나타납니다. 지우개로 일일이 지우실 필요가 없습니다!
❓ Q4. 학교 컴퓨터를 껐다 켜면 다시 로그인해야 하나요?
로그인 시 [이 기기를 신뢰 기기로 등록]을 체크해 두시면 다음번부터는 스마트폰 OTP 없이 원클릭으로 바로 선생님 계정으로 자동 로그인됩니다. 공용 칠판이라면 퇴근 시 [연결 해제]를 눌러주세요.
❓ Q5. 인터넷이 안 되는 교실이나 오프라인에서도 작동하나요?
네! 보데스트의 모든 기본 판서, 전자칠판 화이트보드, 교과서 뷰어, 타이머 기능은 인터넷 연결이 끊어져도 100% 오프라인에서 정상 작동합니다. 인터넷이 다시 연결되면 클라우드 백업이 자동으로 동기화됩니다.
