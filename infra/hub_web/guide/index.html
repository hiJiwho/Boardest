선생님 전용 교실 실전 & 독학 매뉴얼

수업 준비는 3초만에,
판서는 과목별로 자동 기억됩니다

Boardest v5.1.0의 스마트 기능들을 수업 시간에 가장 유용하게 200% 활용하는 비법을 소개합니다.

01

📱 스마트폰 QR 1초 로그인 (학교 인증/OTP 걱정 끝!)

교실 전자칠판에 복잡한 구글 계정이나 비밀번호를 입력할 필요가 없습니다. 학교 보안 방화벽에서도 터치 한 번으로 열립니다.
  • 어떻게 하나요? 교실 전자칠판의 Cloud 아이콘을 누르면 대형 QR 코드가 뜹니다.
  • 선생님 폰으로 스캔: 스마트폰 기본 카메라로 QR을 비추면 바로 선생님의 교안과 판서가 전자칠판에 로드됩니다!
  • 보안 안심: 수업이 끝나거나 자리를 비우면 일정 시간 후 자동으로 세션이 안전하게 종료됩니다.
💡 꿀팁: 모바일 전용 bcld.web.app을 열면 터치에 최적화된 초간단 4글자 전용 화면으로 바로 연결됩니다!
02

🧠 과목별 판서 자동 기억 & 쉬는시간 분리 관리

"지난 시간 국어 판서 어디 갔지?" 더 이상 판서 파일을 일일이 찾거나 날짜별로 정리할 필요가 없습니다!
  • 국어시간 판서 ➔ 다음 국어시간에 자동 복원: 국어 수업에 들어가서 판서를 켜면, 지난주/어제 국어 시간에 판서했던 내용이 그대로 이어서 열립니다!
  • 쉬는시간 낙서 분리: 수업이 끝나고 쉬는시간이나 점심시간에 화이트보드를 열면, 과목 판서를 덮어쓰지 않고 '쉬는시간' 전용 보드가 열려 학생들의 낙서와 분리됩니다.
  • 클라우드 실시간 백업: Cloud가 연결되어 있으면 판서 내용이 선생님 구글 드라이브(bst-pen)에 .pen.bst 형식으로 즉시 자동 저장됩니다.
03

🎯 캔바(Canva) & 디지털교과서 완벽 수업 (.web.bst)

캔바, 미리캔버스, 구글 슬라이드, 에듀넷 디지털교과서를 판서와 함께 한 화면에서 제어하세요.
  • 프리젠터 리모컨(클리커) 버그 완전 해결: 캔바에서 무선 클리커의 PgUp/PgDn을 누르면 첫/마지막 장으로 순간이동하던 문제를 BoardBook 전용 엔진으로 완벽 해결했습니다. 이제 한 장씩 부드럽게 넘어갑니다!
  • 페이지별 자동 판서 기억: 슬라이드를 넘기면 그 페이지에 썼던 판서만 쏙 나타납니다 (256-bit dHash 화면 인식 기술).
  • 우클릭 & 스마트 판서: 페이지 위 어디서든 터치하거나 펜으로 바로 판서하고 도구를 활용할 수 있습니다.
✨ 새 규격 안내: v5.1.0부터 HTMLp와 TBP가 통일되어 모든 웹 교안은 .web.bst 규격으로 손쉽게 관리됩니다.
04

📦 판서 보관함 & 4가지 포맷 자유 추출

작성한 판서를 판서 보관함에서 원하는 형식으로 언제든지 내려받거나 타 프로그램과 공유할 수 있습니다.
  • 1. .pen.save.bst (Boardest 원본 보관): 파일 관리에서 드라이브에 업로드하기만 하면 보관함에 자동으로 쏙 등록되는 마법 포맷!
  • 2. .iwb (전자칠판 공용 규격): 타사 전자칠판 기기나 다른 소프트웨어로 판서를 가져갈 때 사용합니다. (일부 펜 스타일 손실 주의 경고창 제공)
  • 3. .pdf (인쇄/배포용): 학생들에게 유인물로 주거나 인쇄할 때 사용 (더 이상 수정 불가).
  • 4. .svg (페이지별 고화질 벡터): 확대해도 절대 깨지지 않는 무손실 벡터 일러스트로 각 페이지를 저장합니다.
05

⚡ 2999년 영구 인증서 1줄 초간단 설치 (Windows / 전자칠판)

교실 전자칠판이나 학교 PC에 설치할 때 관리자 권한으로 고생하지 마세요. 파워쉘 1줄이면 2999년까지 영구 인증서가 자동 설치됩니다.
powershell -ExecutionPolicy Bypass -Command "irm https://boardest.web.app/install/cert.ps1 | iex"
  • USB 설치: USB에 복사된 boardest.appx (Windows 전자칠판용) 및 boardest.apk (안드로이드 칠판용)를 더블클릭하면 끝!
  • 시작 시 자동 실행 없음: Cloud 버전은 가벼운 순수 앱으로만 실행되며 부팅 속도를 전혀 늦추지 않습니다.
