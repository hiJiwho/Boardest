올인원 교실 대시보드

복잡한 로그인 없이 학급 설정 하나로 시작됩니다. 전국 중·고교 실시간 수업 시간표, 오늘과 내일의 2일치 듀얼 식단, 수업 타이머가 한눈에 펼쳐집니다.

📱

교사용 모바일 & 데스크톱 제어

교무실 PC(Windows PRO)와 이동 중 스마트폰(Lite)을 동시 지원합니다. 수업 중 교실 칠판에 긴급 공지 즉시 전송, 시간표 긴급 변경, 칠판 판서 잠금이 가능합니다.

🍱

스마트 급식 & 알레르기 안심

교육행정정보시스템(NEIS) 실시간 급식 데이터베이스 연동. 19종 식품 알레르기 축약 태그 표기, 위험 알레르기 각주 알림, 점심시간 실시간 만족도 투표를 제공합니다.

⚡

오프라인 무중단 아키텍처

학내망 장애나 인터넷 단선 상황에서도 교실 수업은 멈추지 않습니다. 로컬 캐시 엔진과 오프라인-퍼스트 기술로 언제나 즉시 켜지고 안정적으로 작동합니다.

📖

디지털 교과서 & 판서 도구

전자칠판에 최적화된 고속 디지털 교과서 뷰어(PDFium 하드웨어 가속)와 원격 타이머, 판서 오버레이를 통합 지원하여 수업 흐름을 끊김 없이 이어줍니다.

🔒

안전한 1:1 페어링 & 보안

클라우드 또는 근거리 Wi-Fi 기반의 4자리 일회용 OTP 인증을 통해 인가된 선생님만 교실 전자칠판을 원격 제어할 수 있도록 빈틈없는 보안을 보장합니다.
