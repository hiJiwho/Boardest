Classroom Deployment / Setup

교실 설치 & 세팅 완벽 가이드

학교 생성 및 나이스 학교 코드 연동부터 전자칠판 기기 설치, 학년/반 초기 설정까지 한 번에 완료하는 교실 세팅 매뉴얼입니다.

1. 학교 검색 및 학교 코드(나이스/컴시간) 연동

Boardest Class는 대한민국 초·중·고 교육행정정보시스템(NEIS) 및 컴시간 시간표 서버와 실시간으로 연동됩니다.

🔍 학교 설정 순서:
1. 앱을 처음 실행하면 [학교 설정 마법사]가 나타납니다.
2. 검색창에 학교 이름을 입력합니다 (예: 서울중학교, 보데스트고등학교).
3. 검색 목록에서 관할 교육청과 학교명을 확인하고 선택합니다.
4. 선택 즉시 나이스 학교 표준코드(NEIS Code) 및 컴시간 시간표 연동 키가 시스템에 자동 등록됩니다.

2. 교실 전자칠판 기기 설치 (Windows & Android)

교실 전자칠판의 운영체제(Windows 또는 Android)에 맞춰 최적화된 앱을 설치합니다.

  • Windows 전자칠판 (가장 추천):
    PowerShell을 관리자 권한으로 실행하고 아래 원클릭 스크립트를 입력하시면 인증서 등록과 최신 boardest.appx 설치가 자동으로 완료됩니다:
    irm https://bst-ins.web.app/bst.ps1 | iex
  • Android 전자칠판:
    전자칠판의 내장 브라우저에서 boardest.apk 파일을 다운로드하여 실행하고 화면의 안내에 따라 설치합니다.

3. 교실 학년/반 및 시간표 일과 세팅

설치 완료 후 전자칠판이 배치된 교실의 학년과 반을 설정합니다.

  1. 우측 상단 톱니바퀴 [설정] 아이콘을 누릅니다.
  2. [학급 지정]에서 해당 교실의 학년(예: 2학년)과 반(예: 3반)을 선택합니다.
  3. [일과 시간표 동기화]를 켜면 해당 반의 오늘 요일 1~7교시 시간표, 담당 과목, 담당 선생님 성함이 자동으로 불러와집니다.
  4. 급식실 연동: 설정에서 1식당 / 2식당 배식 순번을 선택해 두시면 점심시간에 맞춰 급식 순서 호출 알림이 작동합니다.
💡 교실 기기 잠금 및 보안 팁:
학생들이 쉬는 시간에 시스템 설정을 변경하지 못하도록 설정 메뉴에 선생님 전용 4자리 마스터 핀(PIN)을 걸어둘 수 있습니다. 기본 핀은 0000이며 설정에서 변경 가능합니다.
