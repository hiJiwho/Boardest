교실 도구 사용 방법 (학생/교실용)

전자칠판 화면의 실시간 교시 시계, 오늘/내일 급식 식단표, 수행평가 실시간 알람, 판서 펜과 도구함 활용 매뉴얼입니다.

1. 실시간 교시 시계 & 수업/쉬는 시간 자동 감지

화면 중앙 상단에는 실시간 시계와 현재 진행 중인 교시 정보가 표시됩니다.

  • 수업 시간 (초록색 링): 수업 시작과 동시에 잔여 시간이 초 단위로 줄어들며, 교시 종료 5분 전에는 시각적 알림이 켜집니다.
  • 쉬는 시간 / 점심시간 (보라색 링): 다음 교시 시작까지 남은 시간과 다음 시간 이동 수업 교실(예: 과학실, 음악실)을 학생들에게 미리 안내합니다.

2. 오늘 급식 vs 내일 급식 원터치 토글

화면 하단 좌측은 당일 영양 만점 급식 메뉴판입니다.

  • 원터치 토글: 상단의 [오늘 급식] / [내일 급식] 버튼을 탭하면 내일 점심 식단표와 칼로리 정보로 즉시 전환됩니다.
  • 알레르기 번호 확인: 각 식단 옆에 알레르기 유발 유발 번호가 안내되어 학생들의 건강과 안전을 보호합니다.
  • 형광펜 기능: 전자칠판에서 내가 좋아하는 메뉴를 손가락으로 꾹 누르면 형광펜 하이라이트가 켜집니다.

3. 수행평가 공지 & [오늘 수행!/내일 수행!] 실시간 알람

급식 메뉴판 바로 옆(5:5 분할)에는 우리 반의 마감 임박 수행평가 공지 카드가 항상 노출됩니다.

🚨 실시간 알람 작동 방식:
• 당일 평가: 오늘 치러지는 수행평가가 있으면 제목 옆에 [🚨 오늘 수행!] 빨간색 펄스 알람 뱃지가 켜집니다.
• 전날 예고: 내일 실시되는 수행평가는 [⚠️ 내일 수행!] 주황색 알람 뱃지로 미리 예고됩니다.
• 항목 순서: [과목] [제목] [실시 날짜/교시] [D-Day 뱃지] 순서로 명확하게 배치되어 시험 범위를 한눈에 파악할 수 있습니다.

4. 수업 펜 판서 모드 (Boardest Pen)

전자칠판 하단의 연필 모양 플로팅 버튼을 누르면 즉시 전체화면 수업 판서 모드로 진입합니다.

  • 다양한 펜 도구: 볼펜, 형광펜, 레이저 포인터, 사각형/직선/원형 도형 그리기 지원
  • 터치 필압 감지: 전자칠판 전용 스타일러스 펜의 굵기 필압을 실시간으로 반영하여 자연스러운 판서 필기감을 제공합니다.
  • 페이지 캡처 & 복사: 중요한 필기 내용을 캡처하여 클라우드에 저장하거나 다음 시간에 다시 열어볼 수 있습니다.

5. 하단 앱 런처 도구함 (타이머, 주사위, 모둠 추첨)

수업 중 자주 사용하는 도구들을 칠판 하단 독(Dock)에서 탭 한 번으로 실행할 수 있습니다:

  • 활동 타이머: 모둠 토론이나 발표 시간 제한을 둘 때 스톱워치/타이머 창을 분할 실행
  • 발표자 뽑기: 번호 추첨 및 무작위 주사위 굴리기
  • 커스텀 앱 바로가기: EBS, 유튜브, 한글/파워포인트 바로가기 아이콘을 슬롯에 등록하여 원클릭 실행
