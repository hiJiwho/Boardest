Boardest 체험 가이드
가상 학급 시뮬레이션 & 데모 이용 방법

기존 분리 운영되던 가상 체험관이 Boardest Class 통합 앱으로 완전 단일화되었습니다.
실제 학교 등록 없이 간편하게 Boardest의 모든 기능을 둘러보는 방법을 안내합니다.

🏫 1. Boardest Class 가상 학급 데모 체험
  • 웹 브라우저 접속: boardest-class.web.app?demo=yes 로 접속하시면 학교 설정 없이 Demo-class 1~10 비겹침 가상 학급이 자동 배정되어 즉시 대시보드가 열립니다.
  • 설치형 앱 (Windows / Android): 앱 최초 실행 시 나타나는 시작 마법사(Setup Wizard) 1단계에서 Class PRO Demo 카드를 선택하고 [데모 체험 시작]을 누르면 즉시 가상 교실로 진입합니다.
  • 가상 시간표, 실시간 데모 급식표, 14종 수업 도구(타이머, 주사위, 추첨기 등)를 자유롭게 체험하실 수 있습니다.
🚪 2. 데모 모드 탈출 (초기 설정 OOBE 복귀)
  • 탈출 방법: 대시보드 하단 바에 위치한 ⚙️ [설정] 버튼을 1초 이상 길게 꾹 누릅니다 (Long-press).
  • 팝업되는 "Demo 탈출" 확인창에서 [Demo 탈출] 버튼을 클릭하면 가상 데모 상태가 초기화되고, 정식 시작 마법사(Setup Wizard)로 즉시 복귀합니다.
  • 일반 [설정] 클릭 시에도 우측 상단 토스트 알림을 통해 원클릭 탈출이 가능합니다.
👩‍🏫 3. 교사 데모 계정 (?create-Demo=1)
  • 교사용 Google OAuth 로그인 시 주소창 파라미터로 ?create-Demo=1 이 전달되면 임시 데모 교사로 가입 및 분류됩니다 (단, 이미 등록된 정회원은 보호되어 무시됩니다).
  • 데모 교사 계정으로 로그인 시 교실 데모 모드와 동일하게 시뮬레이션 환경으로 자동 연결됩니다.
  • 교사 데모 계정은 실제 정규 특별실의 실시간 데이터 덮어쓰기가 제한된 안전 모드로 운영됩니다.
