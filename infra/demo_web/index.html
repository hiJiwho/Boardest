🪟 Windows PC 데모 전용 앱 원클릭 설치 Windows Only

웹 브라우저를 넘어 실제 전자칠판 Windows 환경과 동일한 네이티브 앱 형태로 데모를 설치해 사용해보실 수 있습니다. (안드로이드는 웹 데모만 지원)

irm https://bst-installer.web.app/install-demo.ps1 | iex

PowerShell에 붙여넣기만 하면 보안 인증서 등록과 함께 바탕화면에 데모 바로가기가 생성됩니다.

💡 가상 체험 안내사항:
• 데모 모드에서는 실제 학교 DB 및 개인 클라우드 데이터에 접근하지 않으며, 전용 가상 시뮬레이션 데이터를 제공합니다.
• ?Demo 파라미터가 있는 상태에서는 일반 계정 로그인이 차단되며 안전하게 데모 계정만 사용됩니다.
• 실제 학교에서 정식으로 운용하시려면 소개 메인 또는 앱 다운로드 센터에서 정식 버전을 설치하세요.
