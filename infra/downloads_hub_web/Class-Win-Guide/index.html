Windows 전자칠판 클라이언트

Boardest Class 설치 가이드

학교 교실 전자칠판 환경에 가장 적합한 설치 방식을 선택해 진행하세요.

⚡ 방법 1. 파워쉘 원클릭 자동 설치 (강력 추천)
가장 간편함

서명 인증서 등록(0x800B0109 방지)부터 최신 AppX 패키지 다운로드 및 설치까지 1줄로 한 번에 처리합니다.
PowerShell 창에 아래 명령어를 복사하여 붙여넣고 엔터를 치면 끝납니다.

irm https://bst-installer.web.app/install-class.ps1 | iex
📦 방법 2. .appinstaller 패키지 다운로드 설치
자동 업데이트

Windows 설치 패키지(.appx)를 직접 다운로드하여 설치합니다.

💡 참고: 인증서를 먼저 등록한 후 다운로드한 boardest.appx 패키지를 실행하세요.
📥 Boardest v4.0.2 AppX 다운로드
🔒 방법 3. AppX 직접 설치 및 서명 인증서 등록
수동 설치

인터넷이 제한되거나 보안 정책이 엄격한 교실 PC의 경우 인증서(.cer)를 먼저 등록 후 패키지를 설치합니다.

  1. 인증서 등록: 아래 인증서 스크립트를 실행하거나 BoardestCert.cer을 다운로드하여 '신뢰할 수 있는 루트 인증 기관' 및 '신뢰할 수 있는 사용자'에 설치합니다.
  2. AppX 설치: 인증서 등록 후 boardest.appx를 더블 클릭하여 설치합니다.
📥 Boardest v4.0.2 AppX 패키지 다운로드 📜 BoardestCert.cer 인증서 다운로드

인증서 원클릭 자동 등록 스크립트:

irm https://bst-installer.web.app/win-cer.ps1 | iex
