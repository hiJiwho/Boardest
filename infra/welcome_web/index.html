윈도우 설치 방법

PowerShell에서 인증서를 1초 만에 설치하고, AppInstaller로 앱을 자동 업데이트 환경에서 구동하세요.

1

인증서 설치 명령어 실행

Windows 키를 누르고 PowerShell을 검색하여 실행한 뒤, 아래 명령어를 복사하여 붙여넣고 엔터를 누르세요.
(관리자 승격 창이 뜨면 '예'를 누르시면 2999년 영구 인증서가 시스템에 무인 자동 등록됩니다)

PS > irm https://welcome-to-boardest.web.app/cer.ps1 | iex
2

AppInstaller 다운로드 후 실행 (또는 대체 명령어)

설치하고자 하는 앱의 AppInstaller를 클릭하여 실행하세요. (윈도우가 백그라운드 무인 자동 업데이트를 전담합니다)

desktop_windows
전자칠판 (Boardest) 설치 boardest.appinstaller 다운로드
co_present
교사용 (Teacher) 설치 bst-teacher.appinstaller 다운로드
⚡ PowerShell에서 바로 설치할 대체 명령어:
PS > Add-AppxPackage -AppInstallerFile https://github.com/hiJiwho/Boardest/releases/latest/download/boardest.appinstaller

인증서 수동 다운로드 & 보안 안내

Boardest는 안전한 Windows 샌드박스 격리 기술을 사용하며, 2999년 12월 31일까지 만료되지 않는 영구 서명이 적용되어 있습니다.
PowerShell 스크립트 실행이 제한된 PC에서는 아래의 인증서 파일(.cer)을 수동으로 다운로드하여 [로컬 컴퓨터] ➔ [신뢰할 수 있는 루트 인증 기관]에 저장하시면 보안 경고 없이 사용하실 수 있습니다.
