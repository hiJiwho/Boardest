AppInstaller 온라인 설치 (가장 추천 ⭐)

적극 권장 (자동 업데이트)

가급적이면 무인 자동 업데이트가 지원되는 AppInstaller를 사용하세요!
새 버전 출시 시 앱 시작 시점에 윈도우 OS가 백그라운드에서 자동으로 최신 상태를 유지하며, 앱 삭제 시 플러그인까지 한 번에 깔끔하게 일괄 제거됩니다.

system_update boardest.appinstaller 다운로드 및 실행
terminal
⚡ PowerShell에서 명령어 한 줄로 바로 설치하기:
PS > Add-AppxPackage -AppInstallerFile https://welcome-to-boardest.web.app/boardest.appinstaller

교사용 모바일 최적화 웹앱 (PWA) 이용 안내

모바일 최적화

💡 교사용 앱은 실시간 구글 드라이브 연동 및 강력한 보안을 위해 별도의 안드로이드 APK를 배포하지 않습니다.
대신 모바일 스마트폰 화면에 완벽히 최적화된 Teacher Lite 웹앱(PWA)을 홈 화면에 추가하시면 네이티브 앱과 동일하게 사용하실 수 있습니다.

smartphone 교사용 Lite 웹앱 열기 (boardest-teacher-lite.web.app) laptop_mac 태블릿/PC용 전체 웹 열기
add_to_home_screen 스마트폰 홈 화면에 앱처럼 설치하는 3단계 방법:
1 스마트폰 브라우저(Chrome 또는 삼성 인터넷)로 boardest-teacher-lite.web.app에 접속합니다.
2 브라우저 우측 상단 메뉴 버튼(⋮ 또는 ≡)을 누릅니다.
3 [홈 화면에 추가] 또는 [앱 설치]를 누르면 바탕화면에 바로가기 앱 아이콘이 생성되어 주소창 없이 전체 화면으로 구동됩니다!

웹 브라우저 즉시 접속 & 바로가기

설치 불필요

Chrome, Safari, Edge 등 모든 모던 웹 브라우저에서 별도 설치 없이 즉시 실행할 수 있습니다.

open_in_new 전자칠판 웹 바로가기 (boardest.web.app) smartphone 교사용 Lite 웹앱 바로가기
touch_app iOS(아이폰/아이패드) 및 Mac에서 앱처럼 설치하기 (PWA):
1 Safari(사파리) 브라우저에서 해당 사이트로 접속합니다.
2 하단 중앙의 [공유] 버튼 (네모에 위쪽 화살표 모양)을 탭합니다.
3 스크롤을 내려 [홈 화면에 추가]를 누르면 홈 화면에 전용 앱으로 등록됩니다!

Boardest 영구 인증서 (2999년 만료) 수동 다운로드

보안 인증서

Boardest는 윈도우 OS의 강력한 샌드박스 격리 보안 기술을 채택하였으며, 2999년 12월 31일까지 무제한으로 유효한 영구 서명이 적용되어 있습니다.
PowerShell 명령어 실행이 어려운 보안망 환경에서는 인증서 파일(.cer)을 수동 다운로드하여 등록하실 수 있습니다.

file_download BoardestCert.cer 다운로드 code cer.ps1 스크립트 파일 다운로드
shield
수동 설치 시 주의사항 (0x800B0109 방지):
다운로드한 BoardestCert.cer를 더블클릭할 때, [인증서 설치] ➔ [로컬 컴퓨터] 선택 ➔ [모든 인증서를 다음 저장소에 저장] ➔ [신뢰할 수 있는 루트 인증 기관]을 지정하셔야 윈도우 앱 배포 서비스가 정상 신뢰된 앱으로 인식합니다.
