# Boardest 소개 영상 대본

**예상 길이:** 약 4분 20초
**촬영 흐름:** 제품 소개 → 수업 도구 → Class → Teacher → Cloud·호출 → 설치와 마무리

## 0:00–0:25 | 오프닝 — 왜 만들었을까요?

**화면:** 전자칠판 홈 화면, 교실 수업 장면

안녕하세요. 오늘 소개할 Boardest는 전자칠판과 선생님 PC, 학생 교실을 하나로 연결하는 수업 플랫폼입니다. 수업 자료를 찾고, 칠판에 판서하고, 교실에 안내를 보내는 일을 한곳에서 할 수 있도록 만들었습니다. 전자칠판이 있는 교실에서는 Class를, 선생님 자리에서는 Teacher를, 설치 없이 도구만 쓸 때는 Boardest Tools를 이용하면 됩니다.

Boardest를 쓰면 수업 준비부터 자료 공유, 교실 호출까지 앱을 오가며 반복하던 일을 줄이고 수업 흐름에 집중할 수 있습니다.

## 0:25–1:25 | 수업 도구 — 자료를 열고 바로 판서

**화면:** 수업 도구함에서 TBP, Canva, PPT Overlay, PDF, 판서 보관함을 차례로 실행

먼저 TBP는 전자저작물을 수업에 활용할 때 쓰는 교과서 뷰어입니다. 교과서 파일을 열어 필요한 페이지로 이동하고, 그 위에 바로 판서할 수 있습니다. 수업 자료를 TBP 형식으로 묶어 저장해 두면 다음 수업에서도 같은 자료와 흐름을 이어갈 수 있습니다.

Canva in Boardest에서는 Canva 발표 자료를 열어 전자칠판에서 발표할 수 있습니다. PPT Overlay는 파워포인트 앱 위에 판서 레이어를 띄워 슬라이드를 넘기면서 화면 위에 바로 설명을 적을 수 있습니다.

PDF도 열어서 확대하거나 페이지를 이동하며 판서할 수 있습니다. 수업이 끝나면 판서 파일을 `.pen`으로 저장하세요. 판서 보관함에서 파일을 다시 열어 이어서 사용하거나, 선생님과 교실 사이에 자료로 공유할 수 있습니다.

## 1:25–2:15 | Class — 교실 화면과 일과를 한눈에

**화면:** Class 홈, 시간표, 급식 카드, 시계와 남은 시간 표시

Class는 전자칠판용 화면입니다. 홈에서 오늘 수업과 일과를 확인하고, 시간표에서 교시별 과목을 볼 수 있습니다. 급식은 오늘과 다음 날 메뉴를 확인할 수 있고, 큰 시계와 남은 시간 표시로 수업 중인지 쉬는 시간인지 빠르게 파악할 수 있습니다.

더 간단한 화면이 필요하면 Class Lite를 사용할 수 있습니다. 가벼운 화면으로 시간표와 교실 기능을 빠르게 확인하는 버전입니다.

## 2:15–2:55 | Teacher — 수업 준비와 원격 교실 관리

**화면:** Teacher 시간표, 도구 제작, 파일 업로드 화면

Teacher는 선생님을 위한 앱입니다. 내 시간표와 담임 학급 시간표를 확인하고, 타이머나 활동 자료처럼 수업에 필요한 도구를 준비할 수 있습니다. 파일을 Cloud에 업로드해 두면 수업 중 전자칠판에서 바로 열 수 있습니다.

모바일에서는 핵심 기능을 간단히 쓸 수 있는 Teacher Lite 화면을, 컴퓨터에서는 전체 Teacher 화면을 이용할 수 있습니다.

## 2:55–3:40 | Cloud와 호출 — 교사와 교실 연결

**화면:** Cloud 로그인 선택 화면, QR 승인, OTP, 급식 호출과 쪽지 보내기

Boardest Cloud에서는 수업 파일을 올리고 교실에서 열 자료를 관리합니다. 연결할 때는 화면의 QR을 휴대전화로 승인하거나 OTP를 입력할 수 있습니다. 등록한 교사 계정이 있다면 목록에서 선택해 연결할 수도 있습니다.

급식 호출 기능은 온라인 교실에 급식실 이동 안내를 보내고, 쪽지 기능은 반에 연결된 전자칠판으로 전달 사항을 보냅니다. 필요한 반을 확인하고 보내면 교실 화면에서 안내를 받을 수 있습니다.

## 3:40–4:20 | 설치와 첫 설정 — 마무리

**화면:** 다운로드 페이지, Class 초기 설정, 교사 계정 생성 안내, Boardest Tools

Windows에서는 Class PRO와 Teacher PRO를 AppX로 설치하고, Android에서는 APK를 설치할 수 있습니다. Class Lite와 Boardest Tools는 웹에서 바로 열면 됩니다.

Class를 처음 실행하면 학교와 학년, 반을 설정합니다. Teacher를 사용하려면 교사 계정을 만들고 Cloud를 연결하면 준비가 끝납니다. Boardest Tools에서는 판서 칠판, 타이머, 계산기, 추첨 기능을 설치 없이 사용할 수 있습니다.

전자칠판과 선생님, 교실을 이어 주는 Boardest. 필요한 기능을 한곳에서 시작해 보세요. 감사합니다.

## 촬영 메모

- 앱 이름은 화면에 표시되는 명칭을 따라 `Class`, `Class Lite`, `Teacher`, `Teacher Lite`, `Boardest Tools`로 읽습니다.
- 설치 화면에서는 계정 정보, 학교 개인정보, 실제 교실 알림 내용이 노출되지 않도록 데모 데이터를 사용합니다.
- 기능 시연은 대본 순서대로 각 화면을 짧게 보여주고, 로그인·파일 업로드처럼 대기 시간이 생기는 부분은 미리 준비한 화면 녹화로 연결합니다.
