### 3.2 Detailed Error Breakdown

1. **`apps/boardest/lib/services/tbp/tbp_web_capture_web.dart:4:8`**:
   - Error: `Target of URI doesn't exist: 'dart:js_util'` (`uri_does_not_exist`)
   - Explanation: The file is conditionally imported by `tbp_web_capture_helper.dart` (`if (dart.library.html) 'tbp_web_capture_web.dart' as impl;`). However, when Flutter analyzer runs for the Windows desktop platform, `dart:js_util` is not part of the core library bundle for native desktop without web target compilation.
   - Recommended Fix: Replace legacy `dart:js_util` with standard `package:web` / `dart:js_interop` or guard imports using `// ignore: uri_does_not_exist` or exclude from default desktop analysis in `analysis_options.yaml`.

2. **`apps/boardest_teacher/lib/services/tbp/tbp_web_capture_web.dart:4:8` & `lib/services/tbp_crx_bridge_web.dart:6:8`**:
   - Same error: `Target of URI doesn't exist: 'dart:js_util'` (`uri_does_not_exist`).
   - Identical resolution applies.

## 5. Build & Packaging Toolchain Survey

### 5.1 Windows Desktop Packaging Pipeline
1. **MSIX / AppX Packager (`scripts/build_all_appx.ps1`)**:
   - Takes `-AppVersion` parameter (default `5.4.3`).
   - Uses Windows Kit 10 `makeappx.exe` and `signtool.exe`.
   - Packages 4 main apps into MSIX/AppX: `boardest` (Class Pro), `boardest-class-lite`, `boardest-class-cloud`, `bst-overlay-panser`.
   - Injects certificates (`certs\BoardestCert.pfx` or CurrentUser certificate store).
2. **C# Unified Online Installer / Uninstaller (`tools/installer/build_installer.ps1` & `BoardestInstaller.cs`)**:
   - Compiled via `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`.
   - Embedded resources: `Microsoft.Web.WebView2.Core.dll`, `Microsoft.Web.WebView2.WinForms.dll`, `WebView2Loader.dll`, `BoardestCert.cer`.
   - Acts as single polymorphic binary: behaves as installer or uninstaller depending on executable filename (`boardest-teacher-uninstaller.exe`, `uninstall.exe`, `boardest-installer.exe`).
   - Teacher installation target: `%LOCALAPPDATA%\Programs\BoardestTeacher`.
3. **WiX Windows MSI Installer (`scripts/wix_templates/bst-teacher/Product.wxs`)**:
   - Product GUID & UpgradeCode defined for `Boardest Teacher`.
   - Configures `ProgramMenuFolder` (`Boardest\Boardest Teacher.lnk`) and `DesktopFolder` shortcuts.
   - Sets ARP (Add/Remove Programs) icon, help links, and uninstaller registry entries.

### 5.2 Auto-Update Mechanism (`UpdateService.dart`)
- Queries GitHub Releases API: `https://api.github.com/repos/hiJiwho/Boardest/releases`.
- Normalizes version tags: strips leading `v` and ignores 4th digit (e.g., `5.4.3.0` -> `5.4.3`).
- Asset matching logic:
  - Looks for `.msix` or `.appx` matching `boardest-class.msix` / `boardest.msix`.
  - Fallback: `https://github.com/hiJiwho/Boardest/releases/latest/download/boardest-class.msix`.
  - Downloaded to `%APPDATA%\...\Updates\boardest_update_<ver>.msix`.
  - Background installation: triggers Windows App Installer without killing application prematurely.
