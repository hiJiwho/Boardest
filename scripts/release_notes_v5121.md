### Boardest v5.1.2.1 공식 릴리즈

- **주간 시간표 화면 진입 시 비정상 종료(Crash) 완벽 해결**:
  - `TimetableView` 주간 시간표 그리드 렌더링 시 주말 수업 여부(`hasWeekend`)에 따라 테이블 헤더(8열)와 본문 행(6열)의 열 개수 불일치로 발생하던 Flutter 렌더링 어설션 크래시 원천 해결
  - 대시보드에서 이미 로드된 시간표 데이터(`initialTimetableResult`)를 즉각 재사용하여 네트워크 지연 없이 0.1초 만에 시간표 열람 가능
- **앱 상단 헤더 버전 표기 및 자동 업데이트 안정화**:
  - `v5.1.1`로 고정되어 있던 상단 헤더 버전 텍스트를 `v5.1.2.1`로 완벽 최신화
  - `UpdateService` 내부 기본 버전을 `5.1.2.1`로 동기화하여 버전 체크 정상화
- **독립된 Boardest Class Cloud (BCLD) APK 및 AppX 패키지 공식 지원**:
  - **`bcld.apk`**: 시간표/급식 등 상시 런처 기능 없이, 실행 시에만 **선생님 QR 패스키 대기 화면과 클라우드 수업 보관함이 단독으로 뜨는 초경량 수업용 APK** (부팅 시 자동 실행 없음!)
  - **`bcld.appx`**: Windows 전자칠판용 독립 패키지. 로컬 파워포인트(PPT/PPTX) 연동 및 투명 슬라이드쇼 판서 오버레이 지원!
  - 칠판 앱(`boardest`)과 클라우드 앱(`bcld`)이 서로 덮어씌워지지 않고 하나의 기기에 공존 가능
