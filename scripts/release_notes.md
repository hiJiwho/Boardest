### Boardest v5.0.13 Release Notes
- **쪽지 시스템 고도화 및 3종 응답 지원**:
  - `🟢 O (확인)`, `🔴 X (불가)`, `💬 직접 메시지 입력` 3가지 회신 지원
  - 고유 `messageId` 기반 격리 저장(`message_responses/$messageId.json`)으로 기존 응답 덮어쓰기 문제 완벽 해결
  - 교실 $\leftrightarrow$ 교사 양방향 쪽지 지원: 전자칠판 런처에서 `선생님쪽지` 발송 및 교사용 화면 팝업/실시간 브라우저 알림/3종 회신 지원
- **TBP & HTMLP 우측 세로형 플로팅 판서 툴바**:
  - 기존 하단 플로팅 툴바를 우측 세로형 사이드 바로 전면 교체하여 판서 편의성 및 시인성 대폭 개선
- **BoardBook Chrome Extension (CRX) 포팅 및 웹 브릿지 연동**:
  - 크롬 익스텐션 환경에서 TBP/HTMLP 직접 제어 및 세션 토큰 핸드오프 보안 엔진 탑재
  - 플랫폼별 조건부 컴파일(Web vs Native) 분리로 크로스 플랫폼 빌드 안정성 확보
- **인증서 및 배포 패키지 서명 최적화**:
  - Android APK: v1(JAR) + v2 동시 서명(`enableV1Signing = true`, `enableV2Signing = true`) 강제 적용으로 구형/신형 전자칠판 기기 호환성 완벽 확보
  - Android 9999년 정식 릴리즈 키스토어(`boardest_release.keystore`)로 Class Pro / Class Lite 전 기종 서명 통일
  - Windows: 2999년 만료 영구 코드 서명 인증서 적용 및 단일 실행 `install_certificate.bat` 제공
- **버전 표기**: `BOARDEST V.5.0.13` 공식 배포
