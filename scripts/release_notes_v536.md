# 🚀 Boardest v5.3.6 Official Release

## 🌟 주요 업데이트 및 변경 사항

### 1. 📐 TBP dHash 페이지 자동 감지 민감도 대폭 상향 & 16:9 평탄화
- `_samePageThreshold`를 기존 32비트에서 **14비트**로 대폭 상향 조정하여 교과서 본문 텍스트나 그림의 미세한 변화도 즉각 페이지 전환으로 감지합니다.
- dHash 추출 시 16:9 표준 뷰포트 종횡비에 맞춰 캔버스 다운샘플링 및 이미지 스무딩을 적용하여, 전자칠판·태블릿·노트북 등 기기별 해상도 편차를 완벽하게 평탄화했습니다.

### 2. 👆 전자칠판 전용 대형 좌/우 페이지 넘김 플로팅 터치 버튼 탑재
- 교과서 화면 좌측 및 우측에 큼직한 반투명 쉐브론(`<` / `>`) 버튼을 상시 배치하여 상단 툴바에 손을 뻗지 않고도 원클릭으로 페이지를 넘길 수 있습니다.
- 키보드 방향키 이벤트뿐만 아니라 교과서 웹뷰 내부의 `btn_next`, `btn_prev`, `next`, `prev` 등 네비게이션 버튼 DOM을 자동 클릭 연동합니다.

### 3. 📁 Cloud 함 내 `bst-tbp` 폴더 숨김 및 바로가기 연쇄 삭제(Cascade Delete)
- Google Drive 파일 탐색기에서 `bst-tbp`, `bst-textbookpro`, `bst-tbs` 폴더를 화면 목록에서 완전 제외하여 교안 보관함을 깔끔하게 유지합니다.
- 탐색기(`bst-save`)의 `.tbp.bst`, `.tbp` 포인터 바로가기 삭제 시, 연결된 `bst-tbp` 내부의 32자리 프로젝트 실체 데이터 및 판서 폴더를 동시에 영구 삭제합니다.

### 4. 🖥️ TBP WebView 몰입형 임베딩 (창틀/최소화/닫기 숨김)
- TBP 전자교과서 뷰어 실행 시 Windows 타이틀바(`TitleBarStyle.hidden`)를 숨겨 불필요한 시스템 창틀 없이 교과서 화면에만 집중할 수 있는 풀스크린 몰입형 뷰어 환경을 제공합니다.

### 5. ⚡ 초경량 WebView2 온라인 설치 도구 탑재 (~570 KB)
- 기존 무거운 MSI 방식에서 벗어나 570KB 수준의 초경량 온라인 설치 도구(`boardest-teacher-installer.exe`, `boardest-class-installer.exe`, `boardest-cloud-installer.exe`)를 도입했습니다.
- 현대적인 다크 네온 WebView UI로 실시간 다운로드 속도와 진행 상태를 보여주며, 기존 실행 중인 앱을 자동 종료하고 최신 바이너리를 매끄럽게 교체·설치합니다.

### 6. 📦 Windows 배포 현대화: MSIX 패키징 및 신뢰할 수 있는 루트 인증서 자동 등록
- 교실 전자칠판 및 클라우드 버전을 차세대 `.msix` 패키지로 전환했습니다.
- 온라인 설치 도구 내부에 루트 인증서(`BoardestCert.cer`) 자동 등록 메커니즘을 내장하여 번거로운 수동 인증서 등록 절차 없이 원클릭으로 안전하게 앱이 설치 및 자동 갱신됩니다.
