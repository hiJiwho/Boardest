# 🚀 Boardest v5.4.0 Official Release

## 🌟 주요 업데이트 및 변경 사항

### 1. ⚡ Windows 단일 통합 온라인 설치 마법사 & 원격 설치 엔진 (`boardest-windows-installer.web.app`)
- **실행 파일명 기반 자동 감지 & 3-way 앱 선택**:
  - 단일 온라인 설치 실행 파일로 통합되었습니다.
  - 파일명이 `boardest-class`이면 교실 전자칠판용, `boardest-teacher`이면 교사용, `boardest-cloud`이면 클라우드용 앱을 자동으로 설치합니다.
  - 그 외의 파일명으로 실행되면 사용자가 3가지 앱 중 원하는 앱을 직접 선택할 수 있는 안내 화면이 표시됩니다.
- **웹 주도형(Web-Driven) 원격 설치 오케스트레이션**:
  - 설치 레시피, 최신 버전 다운로드 URL 및 인증서/파일 복사 로직을 `https://boardest-windows-installer.web.app` 웹앱에 내장하여, 향후 설치 도구 재빌드 없이도 웹사이트 업데이트만으로 설치 프로세스를 유연하게 개선할 수 있습니다.
- **🛡️ 실행 시 관리자 권한 필수 획득**:
  - `requireAdministrator` 매니페스트 및 런타임 UAC 권한 상승(`runas`)을 기본 탑재하여, 신뢰할 수 있는 루트 인증서 등록 및 시스템 설치 권한을 완벽하게 확보합니다.
- **🔒 엄격한 URL 출처 보안 가드**:
  - 오직 `https://boardest-windows-installer.web.app` 도메인에서 온 메시지만 C# 설치 관리자 호스트가 수신·실행하도록 원천 차단하여 시스템 보안을 극대화했습니다.
- **🪟 네이티브 창틀 & 최소화 전용 창 모드**:
  - 사용자 친화적인 윈도우 창틀을 제공하며, 설치 작업 중 오작동 방지를 위해 닫기 버튼이 비활성화되어 **최소화만 가능**합니다.
- **📊 3단계 실시간 진행률 UI**:
  - **1단계: 보안 인증서 설치** (Teacher 제외, Class/Cloud 전용 `0% ~ 100%`)
  - **2단계: 최신 패키지 다운로드** (`0% ~ 100%`, 실시간 다운로드 용량 및 속도 표시)
  - **3단계: 앱 복사 (또는 MSIX 설치)** (`0% ~ 100%`)

### 2. 📐 TBP 스마트교과서 정밀도 향상 & 우클릭/롱프레스 핫스팟 모달 연동
- **dHash 해밍 거리 임계값 정밀화**:
  - `_resolveCanonicalKey` 해밍 거리 임계값을 36비트에서 **18비트**(`bestDist = 19`)로 조정하여 `TbpDhashEngine`과 일치시키고, 인접 페이지 간 필기 및 핫스팟이 덮어써지는 문제를 원천 해결했습니다.
- **WebView 우클릭 / 롱프레스 핫스팟 모달 연동**:
  - 전자칠판 및 PC 마우스/터치 환경에서 교과서 본문 위를 우클릭하거나 길게 누르면 해당 위치에 즉시 핫스팟 추가 모달이 팝업됩니다.
  - HTMLP 프레젠터 모드에서는 불필요한 핫스팟 추가 버튼이 숨겨집니다.

### 3. ☁️ Cloud 드라이브 포인터 껍데기(`folderId`) 직결 최적화 & 탐색기 기능 확장
- **포인터 껍데기(`.tbp.bst`, `.htmlp.bst`) `folderId` 직결**:
  - 껍데기 파일에 Google Drive 실체 폴더 ID(`folderId`)를 함께 기록하고 우선 참조하여, 교재 열람·암호화 백업(`.save`)·연쇄 삭제 시 수차례 반복되던 불필요한 Drive 검색 API 호출을 제거하고 즉각 로드되도록 최적화했습니다.
- **교사용 클라우드 탐색기(`.tbp.bst`, `.htmlp.bst`) 완벽 지원**:
  - 교사용 클라우드 탐색기에서 `.tbp.bst` 및 `.htmlp.bst` 파일에 정확한 `TBP`/`HTMLP` 뱃지를 표시하고, 카테고리 필터링과 `.save` 백업 다운로드 기능을 지원합니다.
  - 교실용 클라우드 화면에서 `bst-tbp` 내부의 32자리 Hex 실체 폴더가 목록에 중복 노출되지 않도록 필터링했습니다.
